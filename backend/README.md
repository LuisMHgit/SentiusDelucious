# Delivery App

## Descripción
Aplicación web de pedidos a domicilio donde los usuarios pueden iniciar sesión y crear/listar pedidos.

## Tecnologías
- Python 3
- Django
- PostgreSQL

## Requisitos
- Python 3

## Instalación
python -m pip install --upgrade pip
python -m pip install django psycopg2-binary

## Ejecución

python manage.py runserver

## Funcionalidades implementadas
- Login de usuario
- Crear pedidos
- Listar pedidos

## Funcionalidades pendientes
- Editar pedidos
- Eliminar pedidos
